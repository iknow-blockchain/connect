# iKnow Blockchain connection

October 14, 2026: this repository used to hold a setup guide for native Codex. That guide is retired. Its client ID, its invitation-only notice and the old Chia-only address no longer apply.

**Setup steps for every supported AI app are on the Connect page: https://iknowblockchain.com/connect/**

- Connection address: `https://mcp.iknowblockchain.com/mcp`
- Free and read-only. Any account can connect. No wallet, seed phrase or private key is ever needed, and you should never paste one into chat.

## If you followed the old Codex guide

1. Run `codex mcp logout iknow-blockchain`.
2. In your Codex `config.toml`, remove the `[mcp_servers.iknow-blockchain.oauth]` table that sets `client_id = "14C4VTRF1mLTq4Z2j2iyHmnHWvXKjQHG"`. That client ID is being retired and will stop working.
3. Follow the Connect page.

The earlier `https://chia.iknowblockchain.com/mcp` address is gone; Chia is covered by the connection above.
